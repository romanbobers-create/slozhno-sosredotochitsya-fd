# Сложно сосредоточиться

Адаптивный одностраничный сайт с тёмной и светлой темами.

## Возможности

- Переключение тем: <<День>>, <<Авто>>, <<Неон>>.
- Авто режим через `prefers-color-sheme`.
- Mobile first, брейкпоинты 768px и 1024px, резиновая до 1440px.
- Доступность: семантика, `aria-hidden`, `:focus-visible`.

## Стек

HTML, CSS (гриды,переменные, `clamp()`), Vanilla JS. Без сборки.

## Запуск

Открыть `Index.html` в браузере.
